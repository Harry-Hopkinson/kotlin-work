# Task 4.8

This Kotlin Toolchain project demonstrates two different approaches to
building a string iteratively, one bad and the other good. For each
of these cases, it measures the execution time of the process.

Run the demo of the bad approach with

    ./kotlin run -m bad 20

Run the demo of the good approach with

    ./kotlin run -m good 20

Compare the execution times that are displayed.

| Bad | Good |
| :--- | :--- |
| 3.025833ms | 253.833us |
| 2.877167ms | 346.417us |
| 2.853417ms | 258.583us |
| 2.863958ms | 270.583us |
| 3.020167ms | 263.5us |
